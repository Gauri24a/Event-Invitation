# 🎉 Event Invitation Landing Page

A modern, responsive event invitation website built to showcase a large-scale technical and cultural fest.  
This project is being developed step-by-step using web development best practices.

---

## 📌 Project Purpose

This project simulates a real-world event landing page used by organizations to promote seminars, college fests, and large gatherings.  
It is designed to evolve over time from a simple HTML layout into a fully interactive and responsive website.

---

## 🧩 Current Features (HTML Phase)

- Event title and description  
- Hero section with full-width banner image  
- Invitation-style content layout  
- Structured semantic HTML

## 🎯 Why this project?

This project is not just a demo.  
It represents how real event websites are built, starting from layout and gradually adding design and interactivity.

It is designed to demonstrate:
- Clean code structure  
- Frontend development workflow  
- Progressive enhancement
